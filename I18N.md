# Internationalization (i18n) — حوالاتي / My Transfers

The app ships bilingual from day one: **Arabic (RTL, default)** and **English (LTR)**, with
instant runtime switching (no page reload) and persistence in `localStorage`.

## Architecture

| Concern | Where | Notes |
| --- | --- | --- |
| Translations | `src/assets/i18n/{ar,en}.json` | Loaded at runtime by `@ngx-translate/core` |
| ngx-translate wiring | `src/app/app.config.ts` | `provideTranslateService` + HTTP loader, `defaultLanguage: 'ar'` |
| Language state | `src/app/core/language.service.ts` | **Single source of truth** — active lang, `dir`, font, `<title>`, storage |
| Number/date/currency | `src/app/core/format.service.ts` | Uses the `Intl` API so formatting re-runs on language change |
| Format pipes | `src/app/core/localize.pipes.ts` | `localNumber`, `localCurrency`, `localDate` (impure) |
| Validation messages | `src/app/shared/field-error/field-error.ts` | Maps control errors → translation keys |
| Language switcher | `src/app/shared/language-switcher/language-switcher.ts` | Toolbar menu |
| PDF export | `src/app/core/pdf.service.ts` | Rasterizes the live DOM (html2canvas + jsPDF) |

## How switching works

`LanguageService.use(lang)` does everything in one place:

1. `translate.use(lang)` — all `| translate` pipes re-render.
2. Sets `<html>` `lang`, `dir`, and a `lang-ar` / `lang-en` class.
3. Swaps the `--app-font` CSS variable → **Cairo** (Arabic) / **Inter** (English).
4. Updates the browser tab `<title>` from `app.name`.
5. Persists to `localStorage` (`hawalaty.lang`).

**Angular Material** follows the direction via the CDK `[dir]` binding on the shell
(`src/app/app.html`) — the sidenav, dialogs, menus and tables all mirror automatically.

**Tailwind** RTL comes from the `dir` attribute + logical utilities
(`ms-*`, `me-*`, `ps-*`, `pe-*`, `text-start/end`, and `rtl:` / `ltr:` variants).
Prefer these over `ml-*`/`pl-*` so new markup mirrors for free.

## Golden rule — never hardcode strings

```html
<!-- GOOD -->
{{ 'dashboard.title' | translate }}
<!-- BAD -->
Dashboard
```

## Adding a translation key

1. Add the same key to **both** `ar.json` and `en.json` (keep the tree shape identical).
2. Use it: `{{ 'group.key' | translate }}` or `translate.instant('group.key')` in TS.
3. Interpolation: `{{ 'validation.minlength' | translate: { count: 3 } }}`.

## Formatting numbers / dates / currency

```html
{{ amount | localCurrency: 'USD' }}   <!-- ‏١٬٢٥٠٫٥٠ US$   /   $1,250.50 -->
{{ count  | localNumber }}            <!-- ٥              /   5 -->
{{ date   | localDate }}              <!-- ٠١‏/٠٧‏/٢٠٢٦   /   Jul 1, 2026 -->
```

## Adding a third language

1. Create `src/assets/i18n/<code>.json`.
2. Add an entry to `LanguageService.languages` (`code`, `dir`, `locale`, `font`, `label`).
3. Add the font `<link>` in `src/index.html` if it needs a new webfont.

## PDF reports

`PdfService.exportElement(el)` rasterizes an on-screen element, so the PDF inherits the
active language's **direction and font** exactly as rendered — Arabic PDFs come out RTL
with correct shaping, English PDFs LTR — without embedding Arabic TTFs into jsPDF.
The Reports page (`/reports`) captures its `#report` sheet.
